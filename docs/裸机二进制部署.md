# 裸机二进制部署

> 适用：不使用 Docker，直接在一台装有 MySQL 的服务器上运行（本仓库开发调试即此模式）。

## 1. 构建二进制

前提：Go 1.26.5+、Node 24 + pnpm 11（版本与 CI 一致，见 `.github/workflows/build-and-release.yml`）。

```bash
# ① 先构建前端（产物写入 internal/http/static/out，由 go:embed 嵌入二进制）
cd web && pnpm install --frozen-lockfile && pnpm build && cd ..

# ② 再编译 Go（顺序不能颠倒，否则根路径没有页面）
go build -trimpath -ldflags="-s -w" -o vmqfox-api ./cmd/vmqfox-api
```

也可以直接从 GitHub Releases 下载预编译的多架构二进制（`vmqfox-backend-<版本>.tar.gz` 内含各平台可执行文件、`schema.sql` 与 `env.example`），跳过构建。

## 2. 配置 .env

```bash
cp env.example .env   # 本机/单机调试
# 或 cp env.production.example .env   # 生产
```

每个变量的中文注释与默认值见仓库 `env.example` / `env.production.example`（与 `internal/config/config.go` 全量核对过）。必填三件套：`VMQ_TOKEN_SECRET`（≥32 字符）、`VMQ_TOKEN_ISSUER`、`VMQ_TOKEN_TTL`，缺失直接启动失败。

## 3. 初始化数据库

```bash
mysql -h 127.0.0.1 -u vmqfox -p vmq < database/schema.sql

# 从旧 Go-only 版本升级时，必须执行公开令牌迁移（可重复执行，幂等）：
./vmqfox-api -migrate-public-tokens
```

## 4. 初始化管理员

```bash
# 交互式（推荐，密码不回显、二次确认）
./vmqfox-api -init-admin

# 自动化
./vmqfox-api -init-admin -username admin -password 'YourSecurePassword123' -force
# 或经标准输入管道传入密码，避免进程参数泄露
printf '%s\n' 'YourSecurePassword123' | ./vmqfox-api -init-admin -username admin -force
```

## 5. 启动与 systemd 常驻

```bash
./vmqfox-api   # 前台运行验证：浏览器打开 http://127.0.0.1:8080
```

`/`（管理台+收银台）、`/assets/*`（带哈希的静态资源）、`/api/*`（接口）三者同源。

```ini
# /etc/systemd/system/vmqfox-api.service
[Unit]
Description=VMQFox Payment Gateway
After=network.target mysql.service

[Service]
Type=simple
WorkingDirectory=/opt/vmqfox
ExecStart=/opt/vmqfox/vmqfox-api
Restart=always
RestartSec=3
# 以 .env 中 VMQ_* 为准；也可在此显式注入环境变量（环境变量优先于 .env）

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now vmqfox-api
```

## 6. 验证清单

```bash
curl -s http://127.0.0.1:8080/health   # 期望 healthy
curl -s http://127.0.0.1:8080/ready    # 期望 ready
```

随后登录管理台 → 系统设置填「通讯密钥」→ 按[监控端 App 配置](https://github.com/hulisang/vmqfox-backend/wiki/监控端App配置)绑定挂机手机 → 按[epay 商户插件](https://github.com/hulisang/vmqfox-backend/wiki/epay插件)接入商户系统。
